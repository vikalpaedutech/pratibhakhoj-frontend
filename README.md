# PratibhaKhoj Standalone Frontend

Vite + React frontend for the standalone PratibhaKhoj portal.

## API

Default: `http://localhost:8100/api/v1`

Routes used:

- `/auth`
- `/regions`
- `/schools`
- `/students`

## Run

```bash
npm install
npm run dev
```

The Vite server is configured for port `5174`.
